# Changelog

## 0.7.4
- Tile Grid, Cylinder and UVW Map now share one layout: **Setup** (Target, Reference Tile, **Controller** with `Select Controller`), the module settings, then **Options / Apply** with the Apply button always last.

## 0.7.3
- Faces that sit between two or three axes (for example a bevelled cube corner) now follow the higher priority layer instead of ending up on the lowest one. Applies to Tile Grid and UVW Map (Box).

## 0.7.2
- UVW Map (Box) has the same priority layers, `Flip Back Faces` with side and texture direction as Tile Grid.
- The gizmo preview follows these settings.

## 0.7.1
- Tile Grid: new `Select Controller` button; the controller and the preview cube are clearly separated.

## 0.7.0
- New panel `ModwallGN` with tabs for Tile Grid, Cylinder, UVW Map and Vertex Paint.
- Add-on renamed to `ModwallGN (Simple Tile Cutter)`.

## 0.6.x
- Priority layers with `Flip Back Faces`, texture direction (0 / 90 / 180 / 270), live preview, vertex paint tools, UVW Map and Cylinder projection.
